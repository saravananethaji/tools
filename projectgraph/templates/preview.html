Resolution Preview

Test one proposed Maven version change without editing your project. ProjectGraph copies only POM files into a temporary workspace, asks Maven to resolve there, then shows the dependency branches that changed.

Use this after Impact or Vulnerabilities: identify the resolved library, find the POM/BOM/property controlling it, enter the desired version, then preview. A successful preview proves Maven resolution—not build or runtime compatibility.

Which control should I choose?
Direct dependency: the dependency has a version in the selected module POM. · dependencyManagement: the selected POM centrally sets its version. · Imported BOM: change the version of a type=pom, scope=import dependency. · Version property: the dependency uses a value such as ${spring.version}.
